# Task Manager

A simple task manager that runs in the browser. Built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Add, edit and delete tasks
- Title, details, due date and priority for each task
- Mark tasks as completed
- Filter (all / remaining / completed), search and sort
- Progress bar and overdue counter
- Light and dark mode
- Tasks are saved in the browser (localStorage), so they stay after closing the page

## Run it
Open `index.html` in any browser. No installation needed.
